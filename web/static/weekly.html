Дополнительные документы в RAG

Прикрепите PDF, Word или TXT — можно выбрать несколько файлов сразу. Тип определяется по имени: PMI, Kallanish (в т.ч. massmail `.txt`), иначе PDF отчёт / Kallanish.

Тип подставится сам: PMI / PDF отчёт / Kallanish (в т.ч. из .txt).

PDF, Kallanish и PMI в RAG. Все файлы за период брифа («С» / «По») участвуют в генерации, если их тип включён в источниках (Kallanish / PDF отчёт / PMI). Включение и отключение — только там.

2. Источники

Источники сгруппированы по категориям из Excel (лист health, колонка «Категория»): Металлургия РФ / мира, Китай, Макроэкономика РФ / мира. На чипе — тип брифа (новостной / рыночный / все типы). Справа от названия категории — кнопка Все / Снять для выбора всей группы. В группе «Документы RAG»: Kallanish, PDF отчёт, PMI. При выборе шаблона брифа отмечаются подходящие источники. Цифра — сколько новостей или документов за период есть в RAG. Свои Telegram-каналы — в разделе Свои источники.
